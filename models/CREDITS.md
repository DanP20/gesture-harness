# robot.glb

RobotExpressive, from the three.js examples: https://github.com/mrdoob/three.js/tree/dev/examples/models/gltf/RobotExpressive

Model by Tomás Laulhé (Quaternius), https://quaternius.com. CC0 1.0. Before using it in a project, consider supporting the creator's Patreon: https://www.patreon.com/quaternius

Modifications by Don McCurdy: three facial expression morph targets added, converted with FBX2GLTF, duplicate materials removed and metalness reduced.
